# Crusher Material ONNX Model Directory

Place your custom trained `crusher_materials.onnx` classification model in this directory.

Supported Target Material Labels:
- `BOULDER`
- `40 MM METAL`
- `20 MM METAL`
- `10 MM METAL`
- `6 MM METAL`
- `M-SAND`
- `CRUSHER DUST`

Input tensor shape: `(1, 3, 224, 224)` (Normalized ImageNet RGB).
